# Omni API by Engine

> Omni is Engine's hotel booking infrastructure. Partners use the Omni API (gRPC and HTTP/JSON) to shop, price, and book hotels inside their own product, or Omni Go to send customers to a hosted, co-branded Engine booking experience.
